# Результаты исследования

`figures/` содержит сохранённые сводные графики исходного исследования:
общую и групповые кривые Kaplan–Meier, forest plots одновариантной и основной
многофакторной Cox-моделей. Они перенесены из предоставленных материалов.

`tables/reference_*.csv` и `reference_survival_summary.json` переписаны из
сохранённых outputs ноутбука. Это результаты исходного расчёта, а не нового запуска.
`cohort_summary.json`, `missingness.csv` и `descriptive_statistics.csv` —
описательные агрегаты предоставленного подготовленного v4 CSV без идентификаторов.

`private/reference/` хранит локальные исторические графики с индивидуальными
точками или ошибочными подписями методов. Они исключены из Git. Отчёты в PDF
и их извлечённые тексты не копируются.

`private/runs/current/` предназначен для будущих запусков по явному запросу.
Новые расчёты не перезаписывают сводные результаты в публичных каталогах.
