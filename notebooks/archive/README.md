# Исторические версии

Здесь сохранён исходный код подготовки v1, v2, v4 и анализа выживаемости автора.
Выводы ячеек, вложенные изображения и метаданные среды удалены.
Архив служит для чтения истории исследования. Он не входит в основной маршрут
и ожидает исходные закрытые файлы, которые в репозиторий не перенесены.

Для работы с минимизированными локальными CSV используйте `../01_prepare_data.ipynb`
и `../02_survival_analysis.ipynb`. Численные данные и выполненные копии ноутбуков
сохраняются только в private/.

В историческом анализе есть неточные обозначения Fine–Gray. Подробности и
изменения основного маршрута приведены в `../../docs/methods.md`.
